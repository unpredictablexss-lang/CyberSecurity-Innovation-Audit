# OHScanner 项目文档

本目录面向项目评阅、部署和演示。内容按当前 main 源码整理，核对基线为 `3fc4b1d6bc7664538edbd3ab1aa88ace0a5e4aad`（2026-10-23）；文档整理日期为 2026-10-27。

OHScanner 是面向 OpenHarmony 的源码安全审计工作台：固定源码版本后运行自研静态检测，对候选进行模型辅助调查、人工复核及适用的隔离测试，并保留可追溯的报告。

## 结果如何理解

任务完成、候选命中、源码链可信和漏洞复现是不同结论。候选与模型判断需要结合源码、入口、权限、触发条件及实际影响进行复核。解析失败、缺少上下文和未执行测试均保留为未知，不能当作安全结论。

当前文档不再混排临时分支、机器目录、PR 清单与逐日开发流水。整理前的文档可从[固定版本](https://github.com/unpredictablexss-lang/CyberSecurity-Innovation-Audit/tree/3fc4b1d6bc7664538edbd3ab1aa88ace0a5e4aad/docs)追溯；历史实验原始材料继续保留在研究和基准目录。
