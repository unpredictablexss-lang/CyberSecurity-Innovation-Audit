## Explicit remaining defect; not a passed control

`KNOWN_ALL_RETURN_SOURCE` in the independent test and named replay row `known-all-return-unreachable-log` preserve this counterexample:

```cpp
unsigned *p=&first;
switch(selector){case 0:return;default:return;}
*p=(unsigned char)key[0];
HILOG_INFO(1,"%{public}u",first);
```

Every possible dispatch returns from Callback. The following write and log are unreachable. Baseline and final nevertheless emit the first-log candidate, with source trace parameter 0 -> assignment first -> HILOG. This is a concrete existing over-candidate caused by the unsupported-switch may-flow scan restoring a fallthrough state after scanning return statements as generic effects. It was immediately reported to D97 and owner. D97 scope deliberately does not implement general case exits; this observation is labeled **known_gap_not_passed**, excluded from passing method assertions, and retained with full actual evidence. A useful next slice is bounded complete switch termination/live-exit handling, preserving calls/material effects in reachable arms while not reviving a post-switch state when all dispatch arms return. Fallthrough and return-live exact-target precision remain related limitations.
