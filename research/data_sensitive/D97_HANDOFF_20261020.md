# D97 structured handoff: exact switch pointer target joins

## Problem and reproduction

Baseline owner `73b9a761eb06b11a383793e24ccc6a01b2e4c440` merged without conflict as
`9d5143f8cc301310a840f8d76059aaea075b273c`. Sensitive detector baseline is 0.21.11.
The existing switch may-flow merge keeps the incoming pointer target even when a complete
set of arms all overwrites it with the same destination:

```cpp
void Callback(const char *key, int selector) {
    unsigned first = 0, second = 0;
    unsigned *p = nullptr;
    switch (selector) {
        case 0: p = &second; break;
        default: p = &second; break;
    }
    *p = (unsigned char)key[0];
    HILOG_INFO(1, "%{public}u", second);
}
```

Baseline direct/Runner emit an unresolved material-write candidate at `*p`. For this
shape, whichever label is selected, `p` points to `second` after the switch. The fix
replaces the unresolved-write observation with the actual source-to-second-log candidate.
The total candidate count is unchanged; the destination relation becomes more specific.

## Implementation and changed files

Initial implementation `ae71c3c8e099c42b1d5df81b1fe9c32cddd2a39a`, final correction
`4958df655f86c1199bc326138aaf3b4ecaf9587e`, detector 0.21.11 → 0.21.12.

- `src/ohscanner/detectors/data/sensitive_exposure.py`: `exact_switch_pointer_join`
  accepts only a complete AST and selected units without preprocessor directives; an
  identifier selector; at least two flat arms; unique canonical decimal case labels
  from 0 through 2147483647; exactly one default; and exactly one assignment of the same
  tracked raw pointer to the same bound local non-pointer identifier address, followed
  by a direct break in every arm. Comments are ignored. No calls/declarations/nested
  statements or extra operations are allowed inside arms. Each arm executes on its own
  cloned state and the existing merge combines them, without retaining an impossible
  untouched-entry state. D96 initializer-header restoration still applies.
- `tests/detectors/data/test_d97_switch_same_target.py`: seven developer methods, with
  both pipelines where parser eligibility permits. They cover two/three identical arms,
  default order, old-pointer replacement, uncertain cases, macros/partial input and literal-only writes.
- `D97_probe_switch_join.py`: thirteen fresh-process, full-source archive observations
  at baseline, first implementation and final correction.
- `D97_VALIDATION_20261020.json`: exact source objects/SHA, raw hashes, probes, complete
  direct/Runner records, coverage differences and known-gap evidence.

If the exact shape fails, existing conservative behavior remains. A direct terminal
break has a bounded syntactic meaning here; this is not a general break/return CFG model.
