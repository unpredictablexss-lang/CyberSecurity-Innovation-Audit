## 独立正反控制

所有合成控制使用显式 Callback 参数 0 material source，与参数命名启发式无关。可见的完整自定义纯元数据 body 只写 literal enum 并返回 literal status，两个 log 只输出这些标量，direct/Runner 均 0；它是检查既有 same-file flow 的控制，没有冒充原始 NAPI 实现。

以下情况均保留候选：

- 外部 napi_typeof 名称没有定义，包含其未知返回 status 进入日志的 may-flow；完整声明本身也不能证明实现。
- 缺失声明头或声明头 partial；未知 QueryTypeWrapper；napi_typeof 宏覆盖；同名函数指针参数。
- 同名自定义 body 实际记录输入 char*，或返回 char* 后作为所谓 status 记录。它们不能借 NAPI status 规则丢失真正内容。
- 外部真实形态的 `napi_get_value_string_utf8` 内容读取调用仍 unresolved；完整自定义字节复制 body 将输入复制到 output buffer 再日志时，内容候选保留。

机器逐案列出：可见纯元数据 body 0/0、未绑定 API status 日志 1/1、未绑定实际 byte getter 1/1、同名 secret-return body 1/1。未知 getter 的 buffer 写入尚无专用 API 模型；调用本身保留候选，不把未追踪输出误报为已确认安全。
