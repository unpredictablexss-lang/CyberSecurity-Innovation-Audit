# D99 structured handoff: grouped labels and bounded return values

## Problem and reproduction

Owner baseline `4bff1ae5f2e5d955104e58dfd2feb7248bddfb7d` merged without conflict as
`5bcc6551617a3702a3d4f1b038c24e6caef05de9`, detector 0.21.13. Two kinds of failures
were reproduced and shared with T98 before implementation:

```cpp
switch (selector) { case 0: case 1: return; default: return; }
// A subsequent material write/log was incorrectly scanned although unreachable.
```

```cpp
const char *Select(const char *value, int selector) {
    switch (selector) { case 0: case 1: return value; default: return value; }
}
void Callback(const char *key, int selector) {
    const char *output = Select(key, selector);
    HILOG_INFO(1, "%{public}s", output);
}
```

The second example had no candidate despite explicit Callback argument-zero material
reaching the caller log. Unsupported switch scanning preserved expression effects but
lost the return `ExitState` value summary. Return literal/call/comma expressions also
left a spurious post-switch log while actual calls/logs inside those expressions remained.

## Implementation and files

Implementation `f9296a695907845e6bd32598892ff036d4ac62d1`, detector 0.21.13 → 0.21.14.

- `src/ohscanner/detectors/data/sensitive_exposure.py`: consecutive empty case-label
  arms can share the next nonempty arm when that arm is exactly one direct return.
  The final arm must be nonempty. Existing exhaustive/default/unique canonical-label
  checks remain; executable fallthrough and mixed exits are not generalized.

  parentheses, direct identifier calls with recursively supported arguments, and comma
  expressions. Other syntax remains conservative. Unknown callee identity is preserved
  as an obligation; it does not become a clean transformation.

  Its real effects execute in analysis and its value flows remain in `ExitState.returned`,
  allowing existing bounded helper summaries to propagate material to the caller.
- `tests/detectors/data/test_d99_switch_groups_values.py`: eight developer methods.
  The D98 return-call regression test now expects the actual LeakKey candidate to remain
  while its newly proved dead successor disappears. Historical evidence files are unchanged.
- `D99_probe_grouped_values.py` and `D99_VALIDATION_20261020.json`: seventeen frozen
  full-source/fresh-process controls and complete fixed real-source comparison evidence.

The previous selected-input completeness, no-preprocessor and whole-function goto/label
guards stay active. D97's pointer join and D98's bare-return support remain compatible.
