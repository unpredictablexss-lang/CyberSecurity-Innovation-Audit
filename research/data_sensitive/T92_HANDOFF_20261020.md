## 独立边界控制

全部合成控制使用显式 Callback 参数 0 material source。完整自定义 length helper 借既有 strlen 标量模型，将长度写到输出并返回 literal status；length/status 日志和 length 条件分支都不生成 material 候选。这个 invented body 是可见 flow 对照，没有冒充外部真实 NAPI 函数，也不将一般长度/状态信息定义为 universally public。

反控制保留候选：外部未知 query 和其未知 status 返回进入日志；只有声明、缺失声明或 partial 声明；同名自定义 query 实际记录输入内容；同名函数返回 char* 内容而不是 status；callback、宏覆盖、未知 wrapper；非空真实 buffer getter。可见 memcpy_s→buffer→HILOG 的内容流保留。额外自定义 strlen 会记录输入时也保留，不能因 helper 内含 strlen 拼写而借用标量模型丢失副作用。

代表逐案 direct/Runner：visible-length-body metadata log 0/0、unbound query 1/1、unbound byte getter 1/1、custom secret-return log 1/1，两版一致。对未知 getter，输出 length 的写入尚无专用 API 模型；保留调用/未知返回依赖不等于完成输出或隐式流证明。没有为了通过测试压掉现有材料候选。
