## Reproduced defect and contracts

A minimal source contains explicit modeled material source `Callback(const char *key,bool flag)`, two unsigned scalars and outer `unsigned *p=&first`:

```cpp
if (unsigned *p=&second; flag) { *p=(unsigned char)key[0]; }
HILOG_INFO(1,"%{public}u",first);
HILOG_INFO(1,"%{public}u",second);
```

The material write must affect `second`; shadowed outer `p` cannot direct this write into `first`. Baseline reports the first log and misses the second; fixed code reports the second log and no first log. The same identity error occurs with `if(unsigned *p=&second)`, `while(unsigned *p=&second){...;break;}` and `switch(unsigned *p=&second;flag){case 0:...;break;default:break;}`. These are C++ control-header declaration shapes, not calls inferred from API names. D95 had restored top-level `for` header declarations but had not bound declarations nested under condition/init AST nodes.

Independent contracts further cover literal inner writes followed by material outer writes (outer pointer restored after all four control shapes), returning branch restoration, nested compound-block pointer shadow, while body rebind plus break, continue paths, condition assignment without declaration (actual external rebind retained), unknown initializer target (unresolved material-write candidate, never old outer exact sink), external target divergence in an if or switch, branch same/different target regressions, and the prior for-header regression. `memcpy_s` output material still reaches its log, unknown writes retain candidates, literal-only writes and sensitive-named `static_cast<PrivateKeyInfo *>(nullptr)` remain zero-source controls.

Named source text/SHA, direct findings, Runner diagnostics, argument/call facts, target line, status and coverage are embedded for the 21 named replay role contracts. The remaining compound unittest controls are reproducible from the committed test and their per-method execution logs are in both fixed runs. No heuristic name is treated as an independent secret truth label; these synthetic material tests use explicit Callback parameter 0 source modeling. The null-cast control deliberately uses unknown-profile heuristic behavior.

## Boundaries

This is scope binding and conservative may-flow validation, not a general switch/loop CFG proof. For a switch with header variable q and cases rebinding external p, different destinations retain an unresolved write and do not falsely select either exact log. Even both cases rebinding p to the same destination remain conservative unresolved because case exhaustiveness/fallthrough is not modeled; that is recorded as a precision limitation, not a proven clean path or a failed safety test. No labels, accuracy rate, product deployment claim, cleanup exemption or NAPI build-version binding is inferred from candidate counts.
