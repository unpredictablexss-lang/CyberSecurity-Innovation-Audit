# D96 structured handoff: scoped condition pointer declarations

## Problem and reproduction

Baseline owner `9c298fefee8612cb7b00e2657db0e7b5d1c500e8` was merged without conflict
as `bbd8cb4e53472f1a6db2f14f2e0502490fc8d1b1`. D95's for-header correction remains intact.

```cpp
void Callback(const char *key, bool flag) {
    unsigned outer = 0, inner = 0;
    unsigned *p = &outer;
    if (unsigned *p = &inner; flag) { *p = (unsigned char)key[0]; }
    HILOG_INFO(1, "%{public}u", inner);
    HILOG_INFO(1, "%{public}u", outer);
}
```

Baseline direct detector and Runner incorrectly report the outer log and miss the inner
log. The same error occurs with `if (unsigned *p=&inner)`,
`while (unsigned *p=&inner) { ...; break; }` and a switch initializer
`switch (unsigned *p=&inner; flag) { case 0: ...; break; }`.
Condition declarations were traversed for nested effects but never bound as declarations.

## Changes and implementation identity

Implementation commit: `a3d414b600d18aab886a22876669f1d043a98f2f`, detector
`0.21.10` → `0.21.11`.

- `src/ohscanner/detectors/data/sensitive_exposure.py`: evaluate explicit
  `condition_clause` / `init_statement` / declaration header shapes in order; read the
  condition declaration's initializer from its actual declaration value field; enumerate
  declarators by AST field so initializer identifiers cannot become spurious declarations.
  Restore header names at if exits/merges, loop end and switch-header scope end.
- `tests/detectors/data/test_d96_condition_pointer_scope.py`: seven developer methods
  cover the four forms, restoration, literal-only values and assignment without shadow.
- `D96_probe_condition_scope.py`: nine fixed-source controls, frozen full source archives
  and fresh Python processes; reuses the D95 explicit synthetic Callback source-model worker.
- `D96_VALIDATION_20261020.json`: source manifest, hashes, complete diagnostic records,
  coverage and before/after observations.

The switch-specific handling is limited to a visible header declaration. The body remains
a bounded may-flow effects scan; the change does not establish case reachability or ordering.
