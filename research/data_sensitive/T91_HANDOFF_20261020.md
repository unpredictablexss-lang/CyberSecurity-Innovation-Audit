## 正反控制与真实候选差异

只对精确不可变 `(CERT_PRIVATE_KEY,"key")` 的 NAPI read arg2 允许键角色证明，不泛化任意 const string 或任意 literal key。has 只查询存在性，不能把 present 布尔值当 material；get 的中性名称 output 必须生成 `private-key-property output argument 3` 源。独立控制确认 source label 不冒充 password-property。

参数 const-reference、rvalue-reference 和局部不同值 shadow，mutable/dynamic/wrong literal/wrong constant name，输出参数上的实际 privateKey、未知 wrapper，缺失/partial/重复定义头，API 或常量宏覆盖，同名自定义 body 与 callback 都保留候选。先 read 再 LOGE 的新私钥常量不能自动借用旧 password 日志键排除权限。真实字节 getter 继续消费新 output source；未解析输出目的地时保留 unresolved 候选。
