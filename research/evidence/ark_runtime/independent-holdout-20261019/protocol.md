# Frozen protocol
Freeze rule/model version, Git/tree/blob/source hashes, scope, pseudonymous IDs, exposure declarations, labels and scoring before review. Frozen rule specifications for sampling preparation: **RF-DST-TOKEN** (source-derived store token after species-separated allocation), **RF-EXC-ORDER** (result use before pending-exception guard), **RF-ORIGIN-REBIND** (stale token after invalidating effect). Include vulnerable, fixed, safe and unrelated controls. Exclude mixed revisions, missing bindings, duplicates, leakage, exposed reviewers and unsupported semantics. Unknown, partial, failed, not_applicable, unlabelled and disputed cases are never safe/miss. Reviewers label independently; adjudication is source-only. Tuning invalidates the set for scoring. Source shape does not prove reachability or CIA impact.
