## 日常工作

1. 核对当前目录、分支、HEAD 与未提交改动；自行记录基线，不等待 integrator 发 manifest。
2. 按当前任务选择可执行的代码/测试切片；复用现有环境与未被占用的端口、独立测试数据。
3. 改动涉及公共文件时检查调用者与兼容性，保留并发改动；无需接口申请或单独授权。
4. 运行与改动相关的验证。ownership 检查可选，默认提示；未登记 lane 不构成只读限制。
5. 提交实际改动、验证结果和剩余 unknown。没有具体缺陷或新输入时结束该切片并推进下一项。
