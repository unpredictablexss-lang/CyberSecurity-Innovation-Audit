# OHScanner 竞赛评委实验材料包

整理日期：2026-10-21（Asia/Shanghai）
本目录集中索引 OHScanner 主线平台与 A/B/C/D 四条研究线、Agent/LLM 对照实验，以及外接 G 盘 OpenHarmony-100 实验的可审阅材料。它是研究证据包，不是“已确认漏洞清单”。

## 先读

1. [实验材料总览与复现入口](实验材料总览与复现入口.md)：项目主张、每条线的实验边界、复现方法和尚缺证据。
2. [来源与版本清单](来源与版本清单.json)：仓库分支、完整提交、原始材料位置、状态与限制。
3. [文件哈希清单](文件哈希清单.json)：本目录纳入文件（不含哈希清单文件自身）的 SHA-256 和字节数。

## 内容

- `A线/`：C/C++ 内存安全候选的交付说明和源码哈希绑定。
- `B线/`：最新已推送 IPC Detector 0.12.12 披露回归，以及 G 盘历史复测 0.12.1。两个时间快照分开保存。
- `C线/`：ArkTS / JS / Runtime C1–C4 研究计划、真实源码观察、回归和性能证据。
- `D线/`：敏感信息流与已披露 CVE 的组件级回放材料。
- `AgentLLM/`：评委版工作流说明、真实 Provider 旧版配对实验与 Fake Provider 离线流程烟测。
- `外接盘_OpenHarmony100/`：G 盘 100 仓库活动的总结、覆盖说明、统计和 B 线复测文件。

## 结论口径

静态候选、公开漏洞修复前后差分、组件 Harness 复现、Agent 工作流可运行，分别是不同证据。它们不能相互替代。除各材料明确记录的组件级重现外，当前材料没有证明 OpenHarmony 产品入口可达或产品影响；主线产品状态仍以 `validated_vulnerability=0` / `unknown` 为准。材料中出现的公开 CVE 表示历史披露身份，不表示当前产品仍受影响。

## 大型原始数据

G 盘最新 OpenHarmony-100 工作簿 `OpenHarmony-100扫描结果_20261018_part211.xlsx` 为 55,844,523 字节，XLSX 内 `sheet3.xml` 解压后超过 1 GB。考虑 Git 仓库维护与评委克隆负担，本包不复制重复工作簿快照；其原始路径、完整 SHA-256 和文件大小记录在 [来源与版本清单](来源与版本清单.json)。该工作簿仍保留在原 G 盘位置，可作为线下提交附件。G 盘上的其余原始 OpenHarmony 源码镜像、缓存、数据库和运行环境未复制。
