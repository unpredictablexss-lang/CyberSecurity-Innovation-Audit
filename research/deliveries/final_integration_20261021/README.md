## 最终行为

- 仓库导入、批次同步/重试、静态/智能多模式、逐端点授权、调查进度、联合调查、风险证据链接与案例报告统一接线。
- Agent 使用有限的累计预算。自动调查默认最多 8 次只读工具调用、单次输出 1,200 Token、累计输入 128,000 Token、累计输出 8,000 Token、300 秒；手动调查可在表单配置。独立 Skeptic、结构修复和草案生成仍计入总 Token 与请求预算。
- 可选 USD 上限只在存在已记录支持费率卡时接受，并在入队前校验授权候选数与 Token 上界；未知费率不冒充已实施美元上限，服务商真实账单未验证。预算、候选数、模型或固定来源改变后必须重新预览授权。
- 超预算、取消、部分证据、源码不可用和未执行均保留真实状态。高可信是候选优先级，严重度、置信度、人工意见和产品确认相互独立。
- 案例报告同时保留固定源码锚点、可审查的修复/安全验证计划、Agent 草案和历史 Harness 证据；多候选案例不得整体提升为 confirmed/reportable。
