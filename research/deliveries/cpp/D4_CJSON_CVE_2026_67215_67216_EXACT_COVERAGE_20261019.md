## Advisory and patch status

- CVE-2026-67216 is exponential algorithmic complexity in recursive `cJSON_Compare()` object matching (CWE-407). The [GitHub Advisory Database entry](https://github.com/advisories/ghsa-ff2v-f99f-wm3f) identifies affected code through v1.7.19; Ubuntu's [CVE status](https://ubuntu.com/security/CVE-2026-67216) says no upstream fix was available as of 2026-08-28.
- CVE-2026-67215 is stack exhaustion when untrusted JSON Patch `add`/`copy` operations amplify nesting and recursive `cJSON_Delete()` cleans it up (CWE-674). Red Hat's [CVE record](https://access.redhat.com/security/cve/cve-2026-67215) and Ubuntu's [CVE status](https://ubuntu.com/security/CVE-2026-67215) state no upstream fix was available as of 2026-08-28.
- Therefore neither issue presently has an authoritative upstream fixed commit/version to bind for an exact vulnerable/fix pair. Absence of a patch does not make v1.7.19 or another source a verified safe control. Safe/fixed replay status remains unknown.
