## Portable patch

`latest_static_09ba5aba_minimal.patch` transforms the exact 09ba file set into the current validated algorithm set. It:

- replaces 09ba's `_trace_use` exception guard with the bounded allocation/helper effect-order tracer;
- adds the missing `runtime_exception.py` that 09ba's tests already import;
- updates 09ba's runtime-exception tests only with an old-model import fallback and five C9 controls;
- restores `EXC01.cpp` and extends `test_exception_guard.py` with copy/store order and zero-length unknown controls.

`old_baseline_7af25f5_minimal.patch` is the corresponding patch for the old C-line baseline. Both patches pass `git apply --check --reverse --ignore-whitespace` against the current dirty worktree.

## Conflicts and exclusions

See `latest_static_09ba5aba_conflicts.json`. Main points:

- `exception_guard.py` is a semantic replacement, not a small cherry-pick.
- `test_runtime_exception.py` must be applied as an update because 09ba already contains a 485-line test module.
- 09ba has CRLF blobs; Git patch checks need `--ignore-whitespace` on this Windows checkout.
- `model.py` is intentionally not patched: 09ba already has `RUNTIME_EXCEPTION_RULE_ID`, model 0.8.10 and static-candidate bindings.
- `known_cves.py` is intentionally not patched: `origin/main` already provides `VERSION = "0.16.0"`.
