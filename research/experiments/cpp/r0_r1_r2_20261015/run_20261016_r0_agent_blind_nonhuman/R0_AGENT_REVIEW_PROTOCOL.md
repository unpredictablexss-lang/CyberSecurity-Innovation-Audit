# A-EXP-01 R0 blinded review execution record

This directory contains append-only records generated by the current Codex agent from the frozen truth-free R0 inputs.

The frozen R0 protocol requires an independent human reviewer. This execution is therefore explicitly `reviewer_kind=agent_not_human` and is not represented as a human baseline. `active_seconds` and `paused_seconds` remain null because no independent human session was observed; synthesizing them would violate the frozen protocol.

Before these records were locked, the generator read only:

- `research/experiments/cpp/r0_r1_r2_20261015/initial_candidate_set.json`
- `research/experiments/cpp/r0_r1_r2_20261015/evidence_catalog.json`
- `research/evidence/cpp/independent_review_20261015/blind_review_packet.json`
- `research/experiments/cpp/r0_r1_r2_20261015/run_20261016_unblock_attempt/r0_review_queue.jsonl`
- frozen non-output contracts needed to apply the decision criteria

It did not open `sealed_item_key.json`, frozen truth labels, historical review labels, other reviewer answers, R1/R2 model outputs, or R2 tool results before `R0_AGENT_REVIEW_LOCK.json` was written. Candidate IDs, reviews, historical reports, and vulnerability states were not modified.

The assessment records are suitable as blinded agent predictions and as a preserved non-human execution attempt. They are not eligible as the independent human R0 arm and cannot establish human active/paused cost.
